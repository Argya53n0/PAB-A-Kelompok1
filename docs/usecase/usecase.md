# Use Case Aplikasi Mobile JOBHUB

## Deskripsi Umum

Aplikasi mobile JOBHUB dikembangkan untuk membantu Job Seeker dalam mencari informasi lowongan pekerjaan, melamar pekerjaan, serta memantau proses rekrutmen melalui perangkat mobile. Fokus pengembangan aplikasi mobile hanya ditujukan untuk aktor Job Seeker, sedangkan fitur Admin dan Perusahaan tetap dikelola melalui aplikasi web.

## Aktor

### Job Seeker

Pengguna yang menggunakan aplikasi untuk:

* Mendaftar akun
* Login ke aplikasi
* Mencari lowongan pekerjaan
* Melihat detail lowongan
* Mengunggah CV
* Mengirim lamaran pekerjaan
* Memantau status lamaran
* Menyimpan lowongan favorit
* Mengelola profil akun

# Daftar Use Case

| ID     | Use Case              | Deskripsi                                                                      | Prioritas   |

| UC-M01 | Daftar Akun           | Job Seeker mendaftarkan akun baru melalui aplikasi mobile                      | Must Have   |

| UC-M05 | Lihat Detail Lowongan | Job Seeker melihat informasi lengkap mengenai lowongan pekerjaan               | Must Have   |
| UC-M06 | Apply Lamaran         | Job Seeker mengirim lamaran pekerjaan melalui aplikasi                         | Must Have   |
| UC-M07 | Upload CV             | Job Seeker mengunggah CV dari perangkat mobile                                 | Must Have   |
| UC-M08 | Track Status Lamaran  | Job Seeker memantau perkembangan status lamaran secara real-time               | Must Have   |
| UC-M09 | Simpan Lowongan       | Job Seeker menyimpan lowongan favorit                                          | Should Have |
| UC-M10 | Edit Profil           | Job Seeker memperbarui data profil dan foto akun                               | Should Have |
| UC-M11 | Notifikasi            | Job Seeker menerima notifikasi perubahan status lamaran                        | Should Have |
| UC-M12 | Logout                | Job Seeker keluar dari aplikasi                                                | Must Have   |
