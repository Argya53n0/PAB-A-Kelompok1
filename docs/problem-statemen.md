# Problem Statement: JOBHUB Mobile

Dalam era mobilitas tinggi, banyak pencari kerja (Job Seeker) merasa kesulitan untuk mencari informasi lowongan, melamar pekerjaan, serta memantau status lamaran mereka secara *real-time* jika harus selalu membuka komputer atau laptop. 

Meskipun platform JOBHUB versi web telah tersedia, ketiadaan akses native dari *smartphone* membuat respons pencari kerja menjadi lebih lambat dan kurang praktis, terutama bagi mereka yang sering bepergian.

**JOBHUB Mobile** dibangun untuk memecahkan masalah ini dengan menyediakan aplikasi Android *native* yang secara khusus didesain bagi pelamar (Job Seeker). Dengan aplikasi ini, pelamar dapat mencari pekerjaan, mengunggah CV langsung dari HP, melamar lowongan dengan satu ketukan, dan mendapatkan pembaruan status lamaran langsung dalam genggaman tangan mereka, kapan saja dan di mana saja.
