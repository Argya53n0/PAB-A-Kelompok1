# User Stories: JOBHUB Mobile (Fokus Job Seeker)

## Aktor Utama: Job Seeker (Pencari Kerja)

- **US-M01:** Sebagai *Job Seeker*, saya ingin dapat mendaftar akun baru melalui HP agar saya dapat mulai menggunakan aplikasi.
- **US-M02:** Sebagai *Job Seeker*, saya ingin masuk (login) ke aplikasi dengan email dan password agar data profil dan lamaran saya tersinkronisasi.
- **US-M03:** Sebagai *Job Seeker*, saya ingin mencari lowongan berdasarkan kata kunci atau perusahaan agar saya menemukan posisi yang relevan.
- **US-M04:** Sebagai *Job Seeker*, saya ingin menggunakan filter lokasi dan kategori agar pencarian lowongan lebih akurat.
- **US-M05:** Sebagai *Job Seeker*, saya ingin membaca detail spesifik suatu lowongan (syarat, gaji, deskripsi) agar saya tahu kecocokannya dengan kemampuan saya.
- **US-M06:** Sebagai *Job Seeker*, saya ingin mengunggah file CV berformat PDF dari penyimpanan HP saya agar bisa digunakan saat melamar.
- **US-M07:** Sebagai *Job Seeker*, saya ingin mengirim lamaran kerja dengan menekan satu tombol "Apply" agar prosesnya cepat.
- **US-M08:** Sebagai *Job Seeker*, saya ingin melihat riwayat dan melacak status (Pending/Reviewed/Accepted/Rejected) lamaran saya agar tidak penasaran dengan hasil rekrutmen.
- **US-M09:** Sebagai *Job Seeker*, saya ingin menyimpan (Bookmark) lowongan yang menarik agar bisa saya lamar di lain waktu.
- **US-M10:** Sebagai *Job Seeker*, saya ingin bisa keluar (logout) dari aplikasi agar akun saya aman jika HP dipinjam orang lain.
